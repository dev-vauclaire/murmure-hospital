Changes: Rust implementation for Windows SMP3700 button control and a separate
diagnostic, with bounded reads, strict message validation and reconnection.
The HID layer only queries identity and mode; it does not change device settings
or LEDs. Button actions are routed to Murmure's existing dictation controller.
The wire format is a reference to validate on the actual device.
